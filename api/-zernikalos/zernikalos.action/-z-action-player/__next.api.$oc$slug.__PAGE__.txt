    <div class="platform-hinted " data-platform-hinted="data-platform-hinted"><div class="content sourceset-dependent-content" data-active="" data-togglable=":engine/commonMain"><div class="symbol monospace"><span class="token keyword">class </span><a href="/api/-zernikalos/zernikalos.action/-z-action-player/">ZActionPlayer</a><span class="source-link-wrapper"><span class="source-link" data-element-type="source-link">(<a href="https://github.com/Zernikalos/Zernikalos/blob/v0.10.1/engine/src/commonMain/kotlin/zernikalos/action/ZActionPlayer.kt#L34">source</a>)</span></span></div><p class="paragraph">Allows playback of skeletal actions stored in <a href="/api/-zernikalos/zernikalos.action/-z-skeletal-action/">ZSkeletalAction</a>.</p><p class="paragraph">Playback is bound to a <a href="/api/-zernikalos/zernikalos.objects/-z-skeleton/">ZSkeleton</a>: this class owns the clock (time, speed, loop, play state) and commits the sampled clip pose to that skeleton inside <a href="/api/-zernikalos/zernikalos.action/-z-action-player/update/">update</a> each frame (wall clock or explicit <a href="/api/-zernikalos/zernikalos.action/-z-action-player/update/">update</a> with elapsed seconds).
