    <div class="platform-hinted " data-platform-hinted="data-platform-hinted"><div class="content sourceset-dependent-content" data-active="" data-togglable=":engine/commonMain"><div class="symbol monospace"><span class="token keyword">class </span><a href="/api/-zernikalos/zernikalos.events.keyboard/-z-keyboard-state/">ZKeyboardState</a><span class="source-link-wrapper"><span class="source-link" data-element-type="source-link">(<a href="https://github.com/Zernikalos/Zernikalos/blob/v0.10.1/engine/src/commonMain/kotlin/zernikalos/events/keyboard/ZKeyboardState.kt#L38">source</a>)</span></span></div><p class="paragraph">Maintains the current state of pressed keyboard keys.</p><p class="paragraph">This class tracks which keys are currently pressed, similar to Unity's <code class="lang-kotlin">Input.GetKey()</code>, Unreal's <code class="lang-kotlin">IsInputKeyDown()</code>, or Godot's <code class="lang-kotlin">Input.is_action_pressed()</code>.</p><p class="paragraph">The state is automatically updated by the event system when keyboard events are processed during the game loop frame update phase. You should not manually update the state; instead, use <a href="/api/-zernikalos/zernikalos.events.keyboard/-z-keyboard-state/is-key-pressed/">isKeyPressed</a> to query the current state of keys.</p></div></div>
