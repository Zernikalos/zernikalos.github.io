    <h1 class="cover"><span><span>ZSkinning</span></span></h1>
    <div class="platform-hinted " data-platform-hinted="data-platform-hinted"><div class="content sourceset-dependent-content" data-active="" data-togglable=":engine/commonMain"><div class="symbol monospace"><div class="block"><div class="block"><span class="token annotation builtin">@</span><span data-unresolved-link="kotlinx.serialization/Serializable///PointingToDeclaration/"><span class="token annotation builtin">Serializable</span></span><span class="token punctuation">(</span><span>with<span class="token operator"> = </span><span data-unresolved-link="zernikalos.components.skeleton/ZSkinningSerializer///PointingToDeclaration/">ZSkinningSerializer::class</span></span><wbr><span class="token punctuation">)</span></div></div><span class="token keyword">class </span><a href="/api/-zernikalos/zernikalos.components.skeleton/-z-skinning/">ZSkinning</a> : <a href="/api/-zernikalos/zernikalos.components/-z-serializable-component/">ZSerializableComponent</a><span class="token operator">&lt;</span><span data-unresolved-link="zernikalos.components.skeleton/ZSkinningData///PointingToDeclaration/">ZSkinningData</span><span class="token operator">&gt; </span><span class="source-link-wrapper"><span class="source-link" data-element-type="source-link">(<a href="https://github.com/Zernikalos/Zernikalos/blob/v0.10.1/engine/src/commonMain/kotlin/zernikalos/components/skeleton/ZSkinning.kt#L31">source</a>)</span></span></div><p class="paragraph">Skin binding between a mesh and a skeleton for skeletal animation.</p><p class="paragraph">Holds the list of bone IDs that influence the mesh, their per-bone inverse bind matrices, and an optional skin-level bind matrix pair used when the mesh node and skeleton root do not share the same transform (e.g. in glTF when skin and mesh are on different nodes).</p><p class="paragraph">Typically created by loaders/exporters and attached to a ZModel together with a ZSkeleton.</p><p class="paragraph"><strong>GPU joint order (per skinned </strong><strong>ZModel</strong><strong>):</strong> <a href="/api/-zernikalos/zernikalos.components.skeleton/-z-skinning/bone-ids/">boneIds</a> defines the row order of the joint palette for that mesh. ZBoneMatrixGenerator collects each joint’s current world pose (<a href="/api/-zernikalos/zernikalos.components.skeleton/-z-bone/pose-matrix/">ZBone.poseMatrix</a>) in that same order. ZInverseBindMatrixGenerator fills the matching inverse-bind uniform from <a href="/api/-zernikalos/zernikalos.components.skeleton/-z-skinning/inverse-bind-matrices/">inverseBindMatrices</a> by index, or falls back to <a href="/api/-zernikalos/zernikalos.components.skeleton/-z-bone/inverse-bind-matrix/">ZBone.inverseBindMatrix</a> when a skin entry is missing — loaders should keep <a href="/api/-zernikalos/zernikalos.components.skeleton/-z-skinning/bone-ids/">boneIds</a> and <a href="/api/-zernikalos/zernikalos.components.skeleton/-z-skinning/inverse-bind-matrices/">inverseBindMatrices</a> aligned. ZModelSkinningMatrixGenerator supplies <a href="/api/-zernikalos/zernikalos.components.skeleton/-z-skinning/model-skin-bind-matrix/">modelSkinBindMatrix</a> / mesh–skeleton node offset separately.</p></div></div>
